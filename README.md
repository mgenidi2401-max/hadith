# شرح المنظومة البيقونية

موقع شخصي لتلخيص دروس الشيخ طارق عوض الله.

## التشغيل على GitHub Pages

1. ارفع جميع الملفات والمجلدات إلى جذر المستودع.
2. افتح Settings ثم Pages.
3. اختر Deploy from a branch.
4. اختر branch: main والمجلد: /(root).
5. انتظر دقائق قليلة.

الرابط سيكون غالبًا:
`https://اسم-المستخدم.github.io/اسم-المستودع/`

## بنية المشروع

- `index.html`: الصفحة الرئيسية.
- `lectures/lecture01.html`: المحاضرة الأولى.
- `assets/css/home.css`: تصميم الصفحة الرئيسية.
- `assets/js/home.js`: البحث والتقدم والوضع الليلي.
